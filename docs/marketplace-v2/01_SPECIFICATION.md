# ТЗ: веб-сервис доставки еды «Тёпло»

Версия от 15.11.2026. Команда: Саидов Шохжахон, Самиев Аюбхон. Город: Ташкент; валюта: UZS. Итоговый срок проекта: **05.12.2026, 20:00 Asia/Tashkent**.

## 1. Назначение и границы

Сайт объединяет несколько ресторанов. Покупатель выбирает ресторан либо находит подходящее блюдо сразу во всех ресторанах по категории и бюджету. Текущий релиз — локальный пользовательский MVP: браузер, Django и файл SQLite на компьютере. Интерфейс адаптируется к узкому экрану. Собственное название и визуальный стиль; функциональным ориентиром служат агрегаторы доставки еды.

Роли: гость просматривает каталог; покупатель ведёт корзину и оформляет заказ; внутренние сотрудники обслуживают заказы через сохранённые веб-панели. Самостоятельная регистрация/изоляция партнёров, реальный эквайринг, отзывы, промокоды и сложная маршрутизация относятся к последующим версиям.

## 3. Изюминка: Умный обед

Покупатель выбирает «Первые блюда», «Вторые блюда», «Горячие блюда», «Фастфуд» или другую категорию и задаёт диапазон, например **40 000–70 000 сум**. В результат попадают доступные блюда всех открытых ресторанов, включая обе границы диапазона. Можно дополнительно искать по названию, выбрать «Без мяса», сортировать и переходить между страницами. Каждая карточка показывает ресторан.

В режиме фильтра диапазон относится к цене одного блюда без доставки. На отдельной странице `/smart-lunch/v2/` пользователь задаёт общий бюджет с доставкой и число людей. Набор включает основное на каждого, а также гарнир или салат и напиток, если в меню ресторана есть подходящие позиции. Результаты ранжируются по близости к бюджету, времени и составу. При отсутствии набора в бюджете показывается доплата для ближайшего варианта, который выполняет остальные условия. Добавление использует существующее подтверждение замены корзины.

## 4. Критерии готовности пользовательского MVP

- [ ] На чистом компьютере приложение запускается по README.
- [ ] Каталог показывает минимум шесть демонстрационных ресторанов и 32 блюда.
- [ ] Горячие блюда 40 000–70 000 сум найдены у нескольких ресторанов.
- [ ] 39 999 и 70 001 сум исключены; 40 000 и 70 000 включены.
- [ ] Закрытый ресторан и недоступное блюдо нельзя оформить.
- [ ] Корзина не очищается без согласия при смене ресторана.
- [ ] Регистрация → корзина → адрес → заказ → история работает.
- [ ] Другой пользователь не видит заказ, повтор POST не создаёт дубликат.
- [ ] RU/UZ/EN и ширины 390/768/1440 проверены вручную.
- [ ] Перезапуск и восстановление копии SQLite проверены на тестовых данных.

Автоматические проверки разработчика не заменяют финальную приёмку команды. Задания, ответственные и сроки — в 08_PROJECT_CHECKLIST.md.
