# Задание 6. Системные требования

| Компонент | Требование |
|---|---|
| Компьютер сервера | Windows 10/11, современный Linux или macOS; Python 3.12+ |
| Процессор / RAM | 2 ядра / минимум 4 GB RAM |
| Диск | От 1 GB для среды, базы и изображений; объём увеличивается с загрузками |
| База данных | Локальная SQLite, файл db.sqlite3 в корне проекта |
| Браузер покупателя | Две последние стабильные версии Chrome, Edge, Firefox или Safari |
| Экран | Адаптивная верстка, контроль 390/768/1440 px |
| Интернет | Нужен для первой установки пакетов и публичного сервиса; основной локальный каталог не зависит от внешних изображений |
| Дополнительно | Клавиатура/мышь либо сенсорный ввод; камера и микрофон не требуются |

Заказы создаются только при доступном сервере. Необязательная карта адреса загружает OpenStreetMap; ручной адрес работает без карты. Геопозиция запрашивается лишь по действию пользователя.

Запуск: python start.py. Данные не удаляются при закрытии браузера или перезапуске компьютера. Сервер должен работать, чтобы сайт открывался. Другой компьютер не получает доступ к локальному адресу автоматически; публичное размещение выполняется отдельно.
