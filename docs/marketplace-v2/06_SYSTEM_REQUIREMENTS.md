## Разрешения и сеть

Интернет обязателен для оформления/оплаты. Геопозиция только по действию для адреса, при отказе ручной ввод. Уведомления с требуемым ОС разрешением, при отказе история работает. Камера, микрофон, контакты и постоянный GPS покупателю не нужны. FCM предполагает соответствующие сервисы устройства, без них заказ остаётся доступен без push. При потере сети можно видеть кэш с давностью; offline-оплаты/оформления нет, после timeout проверяется прежний ключ.

## Веб

Две последние стабильные Chrome/Firefox/Edge и текущий/предыдущий поддерживаемый Safari. ОС, способная запускать эти версии, например Windows11, поддерживаемые macOS/Linux, Android10+ и iOS. Устаревшие Windows7/Android5 не обещаются вместе с новейшим браузером. Ориентир настольного клиента:2ядра/4GB RAM, сайт не требует отдельного1GBдиска. Cookies для сессии, JavaScript для интерактивных функций; проверка360/390/768/1280px. iPhone пока через сайт.

## Сервер

Linux с обновлениями, Python3.12+/Django/DRF, PostgreSQL и persistent media. Начальный стенд4vCPU/8GiB/40GB SSD, размер media/копий отдельно. HTTPS/reverse proxy, непрерывныйworker, SMTP, платёжный sandbox/merchant, FCM. DB/worker не должны засыпать/терять файлы. Эта конфигурация не гарантирует1000–2000пользователей. Пять сервисов и RabbitMQ с отдельнымиБД — последующий этап. Копия только на единственном сервере недостаточна.

Git, IDE, DockerCompose, PostgreSQL, Flutter stable зафиксированной версии, совместимые JDK/AndroidSDK/AndroidStudio. Практический ориентир4ядра/16GBRAM/50GBSSD; вместо эмулятора допустим телефон. Два контрольныхAndroid, один Android10/3GB. Нужны проверки входа/сессии, наличных/online, языков/TalkBack, разрешений/сети, гонокPostgreSQL и restore. iOS-сборка/публикация отдельно.
