# Задание 5. Нефункциональные требования

Проект «Тёпло», веб-доставка еды. Команда: Саидов Шохжахон, Самиев Аюбхон. Значения ниже — цели приёмки, не заявленные результаты измерения.

| ID | Область | Проверяемое требование |
|---|---|---|
| NF-01 | Производительность | На контрольном компьютере с 4 GB RAM и 1000 блюдами p95 каталога ≤2 с при 10 одновременных пользователях; протокол измерения обязателен. |
| NF-02 | Выдача | Не более 12 блюд на странице; изображения загружаются отложенно; ресторан и категория читаются совместно без запроса на каждую карточку. |
| NF-03 | Безопасность | Хеширование паролей средствами Django; POST с CSRF; после входа доступ только к своим заказам/профилю. |
| NF-04 | Цены | Числовые поля валидируются сервером; итог не принимается из браузера; checkout_token уникален. |
| NF-05 | Данные | База, секреты, адреса и телефоны не публикуются в GitHub; конфиденциальные страницы не кэшируются. |
| NF-06 | Передача | Локальная разработка — localhost; при публичном размещении HTTPS, secure cookie, DEBUG=false и собственный SECRET_KEY. |
| NF-07 | Надёжность | Ошибка оформления откатывает транзакцию; повторное подтверждение не дублирует заказ; seed не затирает данные. |
| NF-08 | Резервная копия | Перед обновлением копировать остановленную SQLite и media; еженедельно проверять восстановление на отдельной копии. |
| NF-09 | Масштабирование | SQLite для одного локального узла; рост конкурентной записи требует отдельной проверки и выбора БД. |
| NF-10 | Доступность | Клавиатура, подписанные поля, видимый фокус, понятные ошибки; цель WCAG AA для основного сценария. |
| NF-11 | Адаптивность | На 390/768/1440 px нет горизонтального скролла страницы; кнопки и формы доступны. |
| NF-12 | Языки | RU/UZ/EN для навигации, каталога и основного оформления; редактура оставшихся текстов отражена в плане. |
| NF-13 | Тестирование | Фильтры, границы цен, закрытые рестораны, корзина, права, повторное оформление и миграции покрыты автоматическими проверками; основной сценарий проверен браузером. |
| NF-14 | Поддержка | README содержит запуск, расположение данных, копирование и ограничения. |
| NF-15 | Обновления | git pull, установка зависимостей и migrate после резервной копии; контрольный заказ после обновления. |
| NF-16 | Мониторинг | При размещении контролировать доступность, ошибки 5xx, свободное место и резервные копии. |
| NF-17 | Логи | Ошибки логируются без паролей и банковских данных; события заказа видны только владельцу и сотрудникам. |
| NF-18 | Работа без JS | Фильтр, регистрация, корзина и оформление используют обычные HTTP-формы; JS улучшает интерфейс. |
