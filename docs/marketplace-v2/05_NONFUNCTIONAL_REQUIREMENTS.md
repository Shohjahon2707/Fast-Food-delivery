# Задание 5. Нефункциональные требования

**Статус:** план восстановлен по переписке 15.11.2026. Новые функции не считаются реализованными. Дедлайны исходные; фактическое выполнение требует подтверждения команды.

Проект «Тёпло». Команда: Саидов Шохжахон, Самиев Аюбхон. Численные показатели — цели будущей проверки, не готовые результаты.

## 1. Производительность

- **NF-01:** API: p95 каталога ≤800 мс, обычных запросов ≤1 с, p99 ≤2 с; оформление/подбор p95 ≤2 с; провайдер отдельно.
- **NF-02:** Пилот: 100 сессий/30 rps/15 минут, 5% оформлений, ошибки ≤1%, нет дублей.
- **NF-03:** Следующий этап: 1000 сессий/60 rps/30 мин и 2000/120 rps/10 мин; сервер подбирается по замерам, не обещается по одному пилотному тесту.
- **NF-04:** Android 10/3 GB, RTT ≤200 мс: холодный старт p95 ≤3 с из 30 запусков; локальный отклик ≤200 мс, статус ≤10 с.
- **NF-05:** Фото подходящего размера, пагинация и кэш; устаревшая цена перепроверяется.

## 2. Безопасность

- **NF-06:** Пароли хешируются Django; 2FA TOTP оператора/владельца перед публичным пилотом, покупателю опционально.
- **NF-07:** Минимальные права и серверная проверка чужих объектов на каждом endpoint.
- **NF-08:** HTTPS с проверкой сертификатов; шифрование дисков/копий, секреты вне Git; карточные данные наш сервер не хранит.
- **NF-09:** Android refresh в Keystore-backed secure storage; access ≤10 мин, refresh ротация/отзыв, 30 дней неактивности/максимум90 дней.
- **NF-10:** Cookie/CSRF web, idempotency; redirect не подтверждает платёж.
- **NF-11:** Копии БД раз в6ч, media ежедневно,14дней; restore отдельно, RPO≤6ч/RTO≤4ч.

## 3. Масштабируемость

- **NF-12:** Stateless API можно горизонтально расширять; сессии/media не привязаны к локальному контейнеру.
- **NF-13:** CPU/RAM/БД увеличиваются по измеренному узкому месту.
- **NF-14:** Будущие пять сервисов с отдельными данными; сбой доставки не ломает каталог, намерения действий не теряются.

## 4. Доступность интерфейса

- **NF-15:** Веб WCAG2.2 AA, включая применимое из2.0 AA; ручные клавиатура/фокус/контраст/ошибки плюс автоматический аудит.
- **NF-16:** Android TalkBack, понятные labels, текст200%, зонакасания48dp, статус не только цветом.
- **NF-17:** Отказ GPS/push не блокирует адрес вручную; проверка трёх языков с assistive technology.

## 5. Локализация

- **NF-18:** Полный собственный UI uz/ru/en, системный язык при старте и сохранённый выбор; fallback русский.
- **NF-19:** Выбор не очищает корзину/сессию и не конвертирует деньги; узбекский латиница и Unicode.
- **NF-20:** Flutter ARB/gen-l10n, Django gettext, стабильные API-коды/параметры, plural без склейки фраз.
- **NF-21:** Переводы меню предоставляет ресторан; при отсутствии явно исходный текст, состав/аллергены не выдумываются.
- **NF-22:** UZS, локальный формат, исполнение Asia/Tashkent, timestamp UTC; письма/push по выбранному языку.
- **NF-23:** Нет пропущенных ключей/обрезки; языковая проверка человеком, не одной кнопкой переключения.

## 6. Тестирование

- **NF-24:** Unit бизнес-правил, contract/integration межкомпонентных границ и изменяющих операций.
- **NF-25:** Гонки PostgreSQL, настоящий sandbox ошибок/повторов/возвратов; mock недостаточен.
- **NF-26:** Android/web E2E: вход, адрес, повтор, оплаты, deep links, язык, logout и сеть; push при foreground/background/отказе.
- **NF-27:** Нагрузка, доступность, restore имеют отчёты; непроведённые проверки явно отмечены.

## 7. Поддержка

- **NF-28:** Помощь на трёх языках, обращение по заказу; email/телефон/чат только с реальными ответственными и контактами.
- **NF-29:** Часы и эскалация определены до пилота; 24/7 и мгновенный ответ не обещаются без штата.
- **NF-30:** Документы запуска, API, переводов, возврата, копий и пользовательских ролей без секретов.

## 8. Обновления

- **NF-31:** CI/staging, совместимые миграции и rollback; данные через API без переустановки.
- **NF-32:** Обновления APK через выбранный канал/магазин; автоматическую установку решают ОС/настройки, не самовольный инсталлятор.
- **NF-33:** API поддерживает текущую/предыдущую выпущенную Android-версию минимум90дней; критический update показывает помощь.

## 9. Мониторинг

- **NF-34:** HTTPp95/p99, ошибки, очередь/worker, зависшие оплаты/возвраты, курьеры и инструкции реакции.
- **NF-35:** Подозрительные входы/права и действия оператора, crash/ANR клиента без секретов.
- **NF-36:** Целевое SLO99,5% за месяц внешним мониторингом, не заявляется по краткому тесту.

## 10. Логирование

- **NF-37:** UTC, сервис, уровень, correlation ID, event/object/actor ID; без паролей/токенов/полных адресов/телефонов.
- **NF-38:** Технические логи30дней с ограниченным доступом; срок финансового аудита определяется политикой до live.
- **NF-39:** Ошибки ежедневно в часы пилота, тренды еженедельно; финансовый аудит защищён от редактирования.
